# D2: Generative AI Workload Power Profiles
**Organization:** National Laboratory of the Rockies / U.S. DOE  
**Source URL:** https://data.nlr.gov/submissions/312  
**Local Status:** Downloaded & Extracted (1.02 GB archive, 3,148 CSV traces)

### Description
Contains high-resolution power consumption traces for LLM training and inference workloads (e.g., LLaMA, GPT models across various GPU architectures like A100, H100).
*Note: Due to GitHub file size limits (>100MB), the 1.02 GB raw trace archive is kept locally on disk in EDA Data/D2_NLR_GenAI_Power_Profiles/.*
