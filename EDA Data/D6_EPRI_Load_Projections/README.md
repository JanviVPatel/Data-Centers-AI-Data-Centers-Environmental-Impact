# D6: EPRI U.S. Data Center Load Projections
**Organization:** Electric Power Research Institute (EPRI)  
**Source URL:** https://powering-intelligence.epri.com/  
**Status:** Interactive Web Dashboard / Manual Download Required  

### Instructions to Add Data
1. Visit https://powering-intelligence.epri.com/ in your browser.
2. Navigate to the State-Level Data Center Power Dashboard.
3. Export the state-level projection spreadsheet and place it in this folder.
